# Voice Input 视觉设计

配套 `gui-product-plan.zh-CN.md`。原型：[`index.html`](index.html)。

## 不照抄谁

Typeless / Wispr 的招牌是：屏幕中央或底部的圆角药丸、波形、盖在文稿上的写作助手。本仓库不是写作助手，是本机按住说话的输入法。界面按输入法来，不按那套 overlay 来。

禁止再用：悬浮波形条、假备忘录封面、宣纸营销桌面、圆形品牌印当主图标。

## 方向

菜单栏是「听 / 本」方块，和系统 中/英 切换同一类物件。按住 Fn 时，一条矩形候选条贴在光标下方，不占屏幕中央。设置长得像系统「输入法」页。

## 令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `ink` | `#22201c` | 正文 |
| `mute` | `#6f6a63` | 次级 |
| `sheet` | `#f7f6f3` | 面板 |
| `line` | `#dedbd4` | 线 |
| `mark` | `#1f1d1a` | 方块「听」 |
| `hot` | `#b42318` | 仅录音 |

字体用系统苹方。方块里的「听」用宋体，和输入法状态栏一致。
